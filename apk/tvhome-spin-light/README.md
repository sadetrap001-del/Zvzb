# TvHome: dönen ışık

`TvHome.apk` = [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) `launcher/` (MIT, c2d6e79) +
bu klasördeki değişiklik: seçili kutunun çevresinde dönen gökkuşağı ışığı (`SpinRimView.java`).
`changes.patch` kaynak değişikliklerinin tamamıdır (dock sırası, config anahtarı, görünümün bağlanması).

Kapatmak için `config.xml` içinde `focus_spin_light` değerini `false` yapıp yeniden derle.
